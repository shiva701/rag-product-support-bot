# Kettlewise K2 Troubleshooting

## Kettle Will Not Turn On
Check that the kettle is seated correctly on the base and the base is plugged in.
Confirm the outlet works by testing another appliance.
If the display stays dark, unplug the base for 30 seconds and try again.

## Error Code E1
E1 means the kettle is empty or below the minimum fill. Add at least 0.5 liters
of water and press START.

## Error Code E2
E2 means the temperature sensor has failed. Unplug the kettle and contact
RAG support. Do not continue using the kettle.

## Error Code E3
E3 means the kettle overheated, usually from boiling dry. Unplug it, let it cool
for 15 minutes, add water, and try again.

## App Cannot Find the Kettle
Make sure your phone is on a 2.4 GHz Wi-Fi network. Move the kettle within
10 meters of the router. Reset pairing by holding START and TEMP for 10 seconds
until the light flashes red, then pair again.

## Water Tastes Metallic or Chalky
This is usually mineral buildup. Descale the kettle (see the User Manual).
A new kettle may have a slight taste for the first few uses; follow the First Use steps.

## Kettle Is Loud While Heating
Some noise is normal. Loud rumbling usually indicates scale buildup; descale the kettle.
